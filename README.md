# Boardscore for Android

Board game match and score tracker for game nights.

**Install:** [boardscore.apk](https://github.com/birdnero/boardscore-releases/releases/latest/download/boardscore.apk), then allow installing from your browser or file manager.

The app keeps its data on the phone and updates its interface by itself. Each release here contains:

- `boardscore.apk`, the app for new installs
- `boardscore-<version>.zip`, the interface bundle installed over the air
- `version.json`, the manifest the app checks on start
